# Reelfold media kit

Reelfold · 千剪 is a free, MIT-licensed creator workbench for macOS.

## Short description

Turn your footage or notes into a set of videos, with captions, covers and versions for each platform. Edit and render on your Mac with the AI you choose.

## What it does

- Plan a themed set from a folder or SD card, then follow and retry individual versions.
- Edit recordings, lessons, interviews, travel footage and finished videos in plain language.
- Record with a teleprompter, camera, microphone and screen sharing.
- Make English and Chinese versions with their own narration, captions and platform lengths.
- Continue editing by transcript or timeline, or export to Premiere Pro, DaVinci Resolve, CapCut / 剪映 or OpenTimelineIO.
- Prepare covers, post copy and a publishing calendar. YouTube uses its official Data API; other platforms have assisted upload. Automatic scheduled YouTube uploading is opt-in.

| Item | Detail |
|---|---|
| License | MIT |
| Price | The app and engine are free. Connected AI services may charge separately. Paid generation needs approval. |
| Desktop | macOS on Apple Silicon; an unsigned Windows preview is available. |
| Engine | Python, also available as the `video-studio` Claude Code skill. |
| AI | Bring a Claude Code or Codex login, a supported coding agent, API credentials or a local model. |
| Processing | Editing and rendering run locally. Cloud AI steps send the inputs those steps need to the selected provider; see the privacy guide. |
| Exports | Platform-specific files, captions, covers, post copy and editing timelines. |
| Contact | [hello@reelfold.com](mailto:hello@reelfold.com) |
