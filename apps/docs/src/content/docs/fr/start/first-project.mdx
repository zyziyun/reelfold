import { Steps, Tabs, TabItem, Aside } from '@astrojs/starlight/components';

Dans ce pas-à-pas, vous transformez un clip face caméra en un short vertical rythmé et sous-titré pour YouTube Shorts et TikTok, avec une couverture et un texte de publication pour chacun. Comptez environ cinq minutes de votre temps ; la machine fait le reste.

## Avant de commencer

- Reelfold est installé : [l’app Mac](/docs/fr/start/install-mac/) ou [le skill Claude Code](/docs/fr/start/install-skill/).
- Vous avez un enregistrement face caméra d’une à trois minutes. Un clip vertical tourné au téléphone donne les meilleurs résultats ; un enregistrement webcam horizontal est recadré en 9:16 autour de votre visage.
- Facultatif : quelques termes que vous prononcez et que la reconnaissance vocale risque de mal transcrire (noms de produits, jargon). Mentionnez-les dans votre demande.

## Créer le short

<Tabs syncKey="form">
<TabItem label="Dans l’app Mac">

<Steps>

1. **Décrivez-le.** Sur l’**Accueil**, tapez votre demande dans la zone de saisie et déposez le clip :

   > Resserre ce clip face caméra : coupe les blancs, les hésitations et les répétitions, accélère à 1,1×, ajoute des sous-titres et une barre de progression, sans accroche. Exporte pour YouTube Shorts et TikTok avec une couverture et un texte de publication.

   Vérifiez le choix de plateformes sous la zone (il ne vaut que pour cette demande), puis cliquez sur **Lancer**.

2. **Laissez tourner.** La demande devient un projet et **Tous les projets** s’ouvre dessus. La [page de suivi en direct](/docs/fr/app/live-run/) montre ce qui se fait, le temps restant et les éléments à mesure qu’ils apparaissent. Vous pouvez partir : la liste **En cours** de l’Accueil garde le fil.

3. **Les hésitations sont jugées pour vous.** Les hésitations évidentes (euh, bégaiements) sont toujours coupées. En [pilote automatique](/docs/fr/app/autopilot/), l’IA juge aussi les cas incertains (« genre », « en fait », une phrase recommencée, une prise refaite) et note ce qu’elle a coupé ou gardé. Après la coupe, Reelfold retranscrit le résultat pour vérifier qu’aucun vrai mot n’a disparu.

4. **Voyez ce que l’IA a décidé.** Sur la page du projet, **Ce que l’IA a décidé** liste chaque choix avec sa raison : les coupes d’hésitations, l’ouverture, la couverture. Cliquez sur **Changer** pour n’importe lequel : la question part dans votre boîte de réception, et seul ce qui en dépend est refait.

5. **Ouvrez le clip terminé.** Il est **Prête à publier**. Cliquez dessus pour changer la couverture, les sous-titres ou les versions, ou demandez-le au chat (« sous-titres plus grands », « une couverture plus calme »). Voir [Modifier un clip terminé](/docs/fr/app/clip-page/).

6. **Publiez.** Vous obtenez un fichier par plateforme, chacun avec sa couverture, son titre, sa description et ses tags. **Programmer** le place dans le calendrier ; à l’heure prévue, Reelfold ouvre la page de mise en ligne de la plateforme dans son navigateur intégré et renseigne le fichier et le texte. C’est vous qui cliquez sur publier.

</Steps>

Vous préférez valider chaque étape ? Passez à **Me demander d’abord** (Réglages › Général › Nouveaux projets). Le bouton devient **Établir un plan** : vous vérifiez le plan, lancez un clip en aperçu et confirmez vous-même les coupes incertaines dans la boîte de réception, sous **Confirmer les coupes d’hésitations**.

</TabItem>
<TabItem label="Avec le skill Claude Code">

<Steps>

1. **Ouvrez Claude Code dans le dossier du clip** et dites ce que vous voulez :

   > Resserre talk.mp4 : coupe les blancs, les hésitations et les répétitions, accélère à 1,1×, ajoute des sous-titres et une barre de progression, sans accroche. Exporte pour YouTube Shorts et TikTok avec une couverture et un texte de publication.

   Le skill oriente la demande vers le [workflow talkinghead](/docs/fr/reference/workflows/talkinghead/). Claude peut vous demander quel style de montage vous préférez (un style posé avec des notes, un style nerveux en coupes rapides, ou un mélange des deux).

2. **Répondez à la fiche de nettoyage.** Claude transcrit le clip et affiche une fiche numérotée : d’abord les lignes à confirmer, puis ce qui sera coupé automatiquement, les blancs à resserrer et ce qui est conservé. Chaque ligne montre les mots autour de la coupe. Répondez avec les numéros :

   ```text
   approve 3,5,9 keep 7
   ```

   `approve` coupe aussi ces lignes ; `keep` les conserve (cela marche aussi sur les lignes automatiques). `approve all` accepte toutes les lignes en attente de confirmation, et les plages comme `approve 2-4` fonctionnent. Après la coupe, le résultat est retranscrit ; si un vrai mot a disparu, Claude vous indique où et renonce à cette coupe.

3. **Vérifiez l’aperçu.** Claude génère quelques images d’aperçu, puis la vidéo complète. Demandez vos modifications avec vos mots (« sous-titres plus grands », « enlève la barre de progression »).

4. **Couverture et texte de publication.** Claude sélectionne des images candidates pour la couverture, la génère, puis rédige un titre, une description et des hashtags dans les limites de chaque plateforme.

5. **Export par plateforme.** Un master propre devient un fichier par plateforme, avec les sous-titres placés à l’écart des boutons de chaque app et le volume sonore réglé sur sa cible. En coulisses, c’est `python -m vstudio.export` avec `--platforms youtube-shorts,tiktok`.

</Steps>

Avec le skill, la publication vous revient : mettez en ligne les fichiers avec le texte de publication qu’il a rédigé.

</TabItem>
</Tabs>

<Aside type="tip">
L’étape de nettoyage utilise le même outil dans tous les workflows qui conservent la parole d’origine : le format de réponse ci-dessus marche donc aussi pour les podcasts, les cours et les vlogs. Détails : [Nettoyage de la parole](/docs/fr/reference/engine/cleanup/).
</Aside>

## Ce que vous obtenez

| Fichier | Description |
|---|---|
| Une vidéo par plateforme | En 9:16, sous-titres dans la zone de sécurité de la plateforme, volume sonore à sa cible |
| Une couverture par plateforme | Dimensionnée pour le fil de cette plateforme |
| Un texte de publication par plateforme | Titre, description et hashtags vérifiés selon les limites de la plateforme |

## Modifier après coup

Chaque clip terminé peut être retouché avec vos mots : « coupe les deux premières secondes », « passe les sous-titres en jaune », « ajoute une version Instagram ». Chaque modification correspond à une étape d’annulation. Voir [Retouches de clips](/docs/fr/concepts/output-edits/).
