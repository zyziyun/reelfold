All projects is every video you made on this Mac in one list, with the selected video's page beside it. It is built for a few videos a week and for a few hundred at once: search, filters, keyboard moves and bulk actions keep it quick.

## The list

Videos are grouped by where they are, each with its current step, progress and time left:

| Group | What is in it |
|---|---|
| **Needs you** | A question, a review or a run that stopped. The same items are in the Inbox |
| **In progress** | Planning, waiting its turn, or being made |
| **Ready to post** | Finished, not scheduled yet |
| **Scheduled** | On the publish calendar |
| **Posted** | Out, with a link to the post |

A project with several clips shows them under its name; a project's question sits on the clip it is about, so there is one row per video. Groups fold, the list folds to a strip (⌘B), and every divider can be dragged (double-click resets it).

## Search and filters

- **Search videos and projects** matches titles, project names and requests.
- **Filters**: **Platform**, **Project** and **Date** (**Today**, **Last 7 days**). **Clear filters** puts everything back.
- **Archived** shows what you archived, with **Restore**.

## Keyboard

Click a row (or move into the list with the arrow keys) and the list has the keyboard:

| Key | What it does |
|---|---|
| J / K (or ↓ / ↑) | Next / previous video |
| ↵ | Go to what needs doing on it (its question, its review, its page) |
| E | Edit it with AI |
| S | Schedule it, or everything picked |
| X | Pick it / unpick it |
| ⌘A | Pick every video shown |
| ⌫ | Archive what is picked (with Undo) |
| Esc | Clear the picks |

⌘-click picks more, ⇧-click picks a range. On Windows, use Ctrl instead of ⌘.

## Bulk actions

With videos picked, a bar shows only the actions that do something for them, each with how many it takes:

- **Approve**: answers their waiting questions the recommended way.
- **Schedule**: puts the finished, unscheduled ones on the calendar in the next free slots, on your default platforms (with Undo).
- **Try again**: runs the failed or stopped step again for each; finished steps are kept.
- **Change with AI…**: say one change ("tighter", "bigger captions", "a calmer cover"). Each project's chat gets the request for exactly the picked videos and shows the changes for you to apply.
- **Archive** (⌫, or the row menu): hides them from the list. Nothing is deleted. A couple of hundred videos archive in about a second.

## Row actions

**⋯** or right-click on a row:

- **Archive** (with Undo) and **Restore**.
- **Delete…**: a request that never became a project is deleted; a project goes to the Trash after you confirm. Your recordings are never deleted, and a project that keeps your footage inside its folder can only be archived.
- **Rename**, **Show in Finder**.
- **Stop** a running project (Try again picks it up where it was) and **Try again** a stopped one.

## The video's page

Selecting a row opens its page on the right:

- **Planning or running**: the [live run page](/docs/app/live-run/), with what it is doing and the pieces made so far.
- **Ready**: the clip page with the player, cover, captions, versions and post copy. See [Edit a finished clip](/docs/app/clip-page/).
- **Needs you**: the question, answered right there.

Every project page also has a chat; see [Project chat and clip chat](/docs/app/chat/).
