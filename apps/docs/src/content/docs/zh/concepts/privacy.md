千剪（Reelfold）在你的 Mac 上剪辑和渲染，转写与免费配音也可以在本机完成。配置的云端 AI 会接收对应步骤需要的输入，包括文字，以及视觉规划所需的参考帧或联系表。选择云端转写时，会把音轨发给对应转写服务；使用云端生成时，会发送该次生成需要的稿子和参考素材。

## 为什么重要

你的录像里有人脸、声音、名字、客户资料，还有随口说的话。把几个小时的原始素材传到云端剪辑工具，是实打实的代价，接客户的活时尤其如此。重活留在本地，也意味着不用等上传，不用按分钟付渲染费。

## 留在你 Mac 上的

- **素材。** 本地剪辑和渲染原地读取原始文件。使用云端服务时，会发送下表所列的输入。接单时只读不写，素材旁边不会多出文件。
- **转写。** 默认在本地跑 whisper（Apple Silicon）。只有你主动选了在线转写服务，才会用它。
- **渲染。** 剪辑、字幕、特效、封面和导出都在本机完成。
- **密钥。** Mac App 里，API key 存进 macOS 钥匙串，界面只显示「是否已设置」。用技能时，配置文件只写环境变量名，不写 key 本身；客户配置文件会拒绝 key 或 token 字段。
- **你的 persona。** `persona.local.yaml`（你的语速、配色、话题标签、术语修正、模型设置）已被 git 忽略，不会被提交出去。

Mac App 的引擎不监听任何网络端口：应用通过应用自己文件夹里的 Unix 域套接字连接它，每次启动生成新的令牌（Windows 上是 `127.0.0.1` 的随机端口，令牌相同）。

## 会发出去的，以及发给谁

只发给你给这项任务指定的服务：

| 步骤 | 发送的内容 | 不发送 |
|---|---|---|
| 接单 | 你的要求、素材摘要（文件名、时长、简短摘录、文档标题）；当你要从录像里挑内容时，附上逐字稿 | 音频、视频、完整文档 |
| 选段规划 | 带时间戳的逐字稿 | 音频、视频、文件路径 |
| 视觉故事与表演剪辑规划 | 参考帧或联系表、素材说明和相关逐字稿 | 完整原视频 |
| 字幕校对和术语表 | 字幕文字和逐字稿文字、你的术语表 | 音频、视频 |
| 成片二次编辑 | 你的修改要求、这条视频的字幕或逐字稿、当前编辑状态 | 音频、视频 |
| 项目对话、成片对话、自动驾驶的选择 | 你的消息或那个问题、这条视频的逐字稿和设置、可选项 | 音频、视频 |
| 讲解视频和课程的脚本与画面 | 你的讲稿或文档文字、脚本、每段的时间 | 音频、视频 |
| 发布文案 | 事实：地点、月份、你的原话和标题、配乐名 | 音频、视频 |
| 在线转写（仅在你选择时） | 音轨 | 视频 |
| 在线配音（仅在你选择时） | 旁白文字 | 其他任何内容 |
| 视频生成，比如 AI 主持人（只在你填了密钥、并批准花费之后） | 这个镜头需要的东西：提示词，以及要让它动起来的图片或声音 | 你的其他素材 |

要让 AI 处理留在本机，请为每个任务及其备用路由都使用本地模型，选本地转写和配音，并关闭云端生成。自定义或 OpenAI 兼容接口只有在服务器本身运行于本机时才算本地；远程接口仍会接收任务输入。下载、检查更新和发布是另外的联网操作。逐字稿里可能有被录到的人的名字和隐私；做客户项目时，优先用本地模型，或者客户认可其数据条款的服务商。

## 留在你 Mac 上的日志

运行的实时输出（Claude Code 或 Codex 的输出流和引擎日志）保存在你的 Mac 上，API 密钥、令牌和密码都会先去掉。**复制诊断报告**（设置 › 高级）里有版本、引擎状态和设置，没有密钥、密码或视频，贴到哪里由你决定。**报告这个问题**会先把整份报告给你看（路径缩写成 `~`，没有文件名、逐字稿、提示词或密钥），再在 GitHub 上打开，由你自己发出去。自动发送崩溃报告默认关闭。

## 下载

应用第一次需要时，会从公开来源下载字体、人脸模型和语音识别模型；有视频第一次要用免费配音时，再下载配音（约 330 MB，来自 Hugging Face）。这些下载不会附带任何关于你或你视频的信息。见 [设置 › 下载内容](/docs/zh/app/settings/#高级)。

## 统计和更新

Mac App 只有一个可选功能会发送匿名使用次数（比如“一批 12 条切片完成”），默认关闭，只有你打开才会发送；发送的每个字段和删除方法见[隐私：千剪会发送什么](/docs/zh/concepts/usage-counts/)。引擎和 Claude Code 技能不发送任何使用数据。安装版会定期（每隔几小时）检查 GitHub 上的公开版本有没有更新，首次运行时会下载字体和模型。设置 `DESK_DISABLE_UPDATES=1` 可以关掉更新检查。

## 嘉宾和画面里的其他人

剪通话、访谈、播客时，由你决定遮谁的脸。每位被选中的嘉宾会被一个跟踪人脸的贴纸盖住，并有覆盖率检查提示跟踪不完整；通话软件的名字条默认打码。call-clips 配方还会停在「确认授权」检查点，确认出镜的人已同意，这一步永远不会被自动回答。公开分享前仍需检查成片中的遮挡。

千剪从不删除你自己的录像。客户批量的素材清理默认关闭，删除前会先列出确切的文件清单，并且需要确认码。
