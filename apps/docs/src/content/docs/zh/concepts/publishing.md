千剪（Reelfold）帮你发，但除非你打开自动发布，它从不替你发。平台有千剪支持的官方上传接口时（目前是 YouTube），就用这个接口。其他平台，Mac App 在内置浏览器里打开平台自己的上传页，放好视频文件，填上标题、正文和话题。你检查一遍，做那些只该由你做的选择，然后自己点发布。

## 为什么重要

发出去的内容是公开的，署的是你的名字。最后一眼应该由你来看：账号对不对、分类、AI 生成声明、可见范围。辅助发布替你做掉繁琐的部分（拖文件、粘文案、每个平台重新输一遍话题），把要紧的部分留给你。没有公开发布接口的平台也能用，国内大部分平台都是这种情况。

## 怎么运作

每个平台只有一条路，在 **设置 › 发布账号** 里标在平台上：**官方 API**（YouTube），或内置浏览器（其他所有平台）。每个平台还都有 **在浏览器中上传**（见下）。

### 在内置浏览器里辅助填写

1. **每个账号一个长期登录。** 你在 App 的浏览器里登录每个平台一次。App 自己从不保存你的密码或 cookie；检测到登录页时会停止填写。有些平台提供「使用 Google 继续」「使用 Facebook 继续」或「通过 Apple 登录」，这些服务不允许在应用内置的浏览器里登录，千剪会把它们的拒绝页换成一段简短说明。请改用平台自己的邮箱、手机号或扫码登录。
2. **自动填写。** 每条帖子，App 打开上传页，放好视频，在页面允许的地方填上标题、正文和话题。
3. **你来发布。** 你检查内容，按需要选分类、可见范围、AI 声明等，然后点平台的发布按钮。App 最多帮你把按钮框出来，永远不会去点它，适配文件里也根本没有「点击」这种写法。
4. **已发布。** 你点了发布之后，千剪继续看着页面；平台确认后，这条标为已发布，页面显示链接时一并记下。也可以手动标记。

每个平台的填写步骤写在一个小的适配文件里。你可以在 `~/Library/Application Support/Reelfold/adapters/` 里新增或覆盖适配文件，不用重新编译 App。没有在真实登录状态下核对过的适配，会标为「未验证」，直到有人对照真实页面检查过。

### YouTube：官方 YouTube Data API

YouTube 只通过 Google 官方 YouTube Data API 发布，从不走内置浏览器（Google 不允许在内嵌浏览器里登录）。

1. **登录一次**：在 **设置 › 发布账号 › YouTube** 点 **在浏览器中用 Google 登录**。Google 的登录页在系统浏览器里打开，千剪看不到你的密码。千剪申请上传视频到你的频道、查看频道名称和播放列表；它不能编辑或删除你的视频。把视频加入播放列表是另一项权限，可以单独允许。令牌保存在 macOS 钥匙串里。
2. **在帖子上发布。** YouTube 帖子显示的是发布表单而不是网页：标题、说明、标签、类别、公开范围、**现在** 或 **定时**、观众（是否为儿童打造，YouTube 要求必须回答）、加工或合成内容的声明、**作为 Shorts 发布**、用封面作缩略图、播放列表。不按 **发布** 或 **定时发布**，什么都不会发出去。
3. **定时的帖子** 现在以私享方式上传，到点由 YouTube 自动公开，电脑休眠也没关系。

来自未通过 YouTube API 审核的 Google Cloud 项目的上传会保持私享，需要你在 YouTube Studio 里改为公开。登录用千剪的 Google 应用（你的版本内置了它时），或 **我自己的 Google Cloud 客户端**（见[排期和发布](/docs/zh/guides/scheduling-publishing/#youtube-登录)）。Mac App Store 版无法登录 YouTube；每条 YouTube 帖子都可以改用 **在浏览器中上传**。

### 在浏览器中上传

每个平台都有 **在浏览器中上传**：上传页在你的默认浏览器里打开（你在那里已经登录），千剪把每一样交给你：显示视频文件让你拖进去，标题、说明和标签一样一样复制。你在那边点发布，再把帖子链接粘贴回来，标记为已发布。

### 什么都不会自己发出去

上传只从你的点击开始（发布、定时发布，或你在填好的页面上点的发布按钮）。例外只有一个：**设置 › 发布账号** 里 YouTube 的 **自动发布排好的视频** 开关，由你自己打开（默认关闭）：打开后，排好的 YouTube 帖子会在时间前约一小时上传。TikTok、X 和 Instagram 列在 **自动发布（官方接口）** 下，标为 **暂不支持**，在那之前用辅助填写。

用技能时，你要在系列或项目文件里明确打开官方接口（`uploader: <名字>`），凭据放在仓库之外，而且每次上传都必须输入你审过的那个发布包的确认码。

### 每个平台的视频时长

不是每个平台都发一样长的视频。YouTube 和 B站 出带章节的长版；Shorts、TikTok、小红书、Instagram 和 LinkedIn 出短版。在 **设置 › 发布账号 › 视频时长** 里按平台设置你自己的最短和最长。见[一个母版发多个平台](/docs/zh/guides/multi-platform/)。

### 不用 Mac App 时

只用技能时，设成 `uploader: manual`，每条帖子会给你上传页地址、操作步骤、文案、封面和一份检查清单。

## 各平台注意事项

- **YouTube：** 只走官方 API，长视频和 Shorts 两种。从千剪作为 Shorts 发布时，视频必须是竖屏或方形，且不超过 60 秒（会加上 `#Shorts`）。
- **Reddit：** subreddit 由你自己填；标题必填，发出后不能改。发之前先看社区规则，很多社区限制自我推广。
- **Pinterest：** 链接放在目标链接栏，不要放进描述。图板由你选。
- **Snapchat Spotlight：** 5 到 60 秒，9:16，不能有水印。
- **Kwai：** 没有电脑网页上传入口，会给你打包好，用手机 App 发。
- **小红书、抖音、视频号、B站、快手、微博、知乎：** 在各自的创作者上传页辅助填写。每个平台都有「内容由 AI 生成」或作者声明的开关，适用时请自己勾上。

## 在 Mac App 里

「发布」页显示你这一周的排期。每条通过审片的视频都备好了文案；打开它，检查填好的页面（或 YouTube 表单），点发布，这条就会标为已发布。

## 用 Claude Code 技能

导出和打包时会附上封面、发布文案和排期表。除非你按上面说的打开了官方接口，否则不会上传任何东西；你可以拿着发布包自己发，或者在 Mac App 里打开项目从那里发布。
