全部项目是你在这台 Mac 上做过的每条视频，放在一个列表里，旁边是选中那条的页面。一周几条可以，一次几百条也可以：搜索、筛选、键盘操作和批量操作让它一直很快。

## 列表

视频按所处阶段分组，每条带当前步骤、进度和剩余时间：

| 分组 | 里面是什么 |
|---|---|
| **要你看** | 一个问题、一次审片，或停下来的运行。收件箱里也是同样这些 |
| **进行中** | 正在出方案、排队，或正在做 |
| **可以发** | 做好了，还没排期 |
| **已排期** | 已经在发布日历上 |
| **已发** | 已经发出去，带帖子链接 |

有多条成片的项目，成片列在项目名下面；项目的问题挂在它所问的那条成片上，所以每条视频只占一行。分组可以折叠，整个列表可以收成一条窄栏（⌘B），每条分隔线都能拖（双击恢复）。

## 搜索和筛选

- **搜视频和项目**：匹配标题、项目名和请求原文。
- **筛选**：**平台**、**项目**和**时间**（**今天**、**最近 7 天**）。「清除筛选」恢复全部。
- **已归档**：显示你归档过的，可以**恢复**。

## 键盘

点一行（或用方向键移进列表），键盘就归列表：

| 按键 | 作用 |
|---|---|
| J / K（或 ↓ / ↑） | 下一条 / 上一条 |
| ↵ | 去它要处理的地方（它的问题、审片或页面） |
| E | 让 AI 改它 |
| S | 给它排期，或给所有选中的排期 |
| X | 选中 / 取消选中 |
| ⌘A | 选中当前显示的所有视频 |
| ⌫ | 归档选中的（可撤销） |
| Esc | 清空选中 |

⌘ 点击多选，⇧ 点击选一个范围。Windows 上用 Ctrl 代替 ⌘。

## 批量操作

选中视频后，操作栏只显示对它们有用的操作，并写明会处理几条：

- **通过**：按推荐答案回答它们在等的问题。
- **排期**：把做好、还没排期的放进日历里接下来的空位，发到你的默认平台（可撤销）。
- **重试**：把每条失败或停下的那一步再跑一次，已完成的步骤保留。
- **让 AI 一起改…**：说一个改动（「再紧凑一点」「字幕大一点」「封面安静一点」）。每个项目的对话会收到这个请求，只针对选中的视频，列出改动等你应用。
- **归档**（⌫ 或行菜单）：从列表里藏起来，什么都不删。两百来条视频大约一秒就能归档完。

## 行菜单

在一行上点 **⋯** 或右键：

- **归档**（可撤销）和**恢复**。
- **删除…**：还没变成项目的请求直接删；项目要你确认后才移到废纸篓。你的原始录像永远不会被删，素材放在项目文件夹里的项目只能归档。
- **重命名**、**在访达中显示**。
- 正在跑的项目可以**停止**（重试时从停下的地方接着做），停下的可以**再试一次**。

## 视频页面

选中一行，右边打开它的页面：

- **正在出方案或正在做**：[实时运行页](/docs/zh/app/live-run/)，显示它在做什么、已经做出来的部分。
- **做好了**：成片页面，有播放器、封面、字幕、版本和发布文案。见 [修改做好的成片](/docs/zh/app/clip-page/)。
- **要你看**：问题就在这里回答。

每个项目页面都有对话，见 [项目对话和成片对话](/docs/zh/app/chat/)。
