---
title: 项目对话和成片对话
description: 在千剪的项目或成片上，可以让对话做什么：暂停、继续、换配乐、重新剪、重新设计画面、跟随主体、重写发布文案，以及能撤销的大白话修改。
---

每个项目页面和每条成片旁边都有对话（**问 AI**）。用你自己的话说想要什么，什么语言都行。对话会给出可以应用、对比和撤销的修改卡片，或者直接控制运行。对话可以收起，也可以调宽窄。

## 项目对话

在正在跑、已经做好或在详情里打开的项目上，对话可以直接控制运行：

| 说 | 会发生什么 |
|---|---|
| 「暂停」 | 在安全的位置停下，已经做好的都不会丢 |
| 「继续」 | 从暂停的地方接着做 |
| 「换个配乐」/ **换配乐** | 回到配乐那一步，在那里问你（要你看），其余都保留 |
| 「换一张封面」 | 同上，针对封面 |
| 「重新剪」/ **重新剪** | 回到剪辑那一步，在那里问你 |
| 「每条都 1.1 倍速」「把所有成片上的系列标签去掉」 | 每条成片一张修改卡片；可以**全部应用**，也可以一条条来 |

输入框上方的范围开关决定这次请求改哪些成片：**全部**，或者**只改**某一条。也可以在[全部项目](/docs/zh/app/all-projects/)里选中多个项目，用**让 AI 一起改…**。

如果还什么都没做出来，对话会告诉你现在能做什么：暂停、重新选配乐或封面，或者重新剪。

## 成片对话

在做好的成片上，对话修改这一条。改动马上生效，每次都能**撤销**（设置里可以打开「应用 AI 修改前先问我」）。常见的请求：

- **时间**：「从『其实诀窍是』开始」「再紧凑一点」「去掉开头两秒」「1.1 倍速」。
- **字幕**：「字幕大一点」「关键词用黄色」「把『免费』这个词突出一下」「字幕放到上面」。
- **版本**：「做一个抖音版」「加一个 YouTube 16:9」「不要 3:4」。
- **封面**：「换个封面」「封面安静一点」。
- **竖屏画面**：「跟随主体」或「模糊填充」，会重新导出竖屏版本。见 [横屏素材的竖屏版本](/docs/zh/guides/vertical-reframe/)。
- **发布文案**：「重写发布文案」，按每个平台的语言重写标题、正文和话题。见 [各平台的发布文案](/docs/zh/guides/post-copy/)。
- **讲解视频的画面**：「画面太素了」「重新设计画面」「多一点图解」。AI 把每一段重新画、重新渲染，配音和字幕不变。见 [讲稿做成课程视频](/docs/zh/guides/course-from-notes/#重新设计画面)。

想自己动手，输入 **/** 打开工具（剪辑、字幕、特效、封面、导出）。

成片做不了的请求会说明原因。比如成品文件里烧进画面的字幕只能加新的，不能改样式；项目还在做东西时，重新导出要等它做完。

## 没有模型，或者模型没回应

对话要靠 AI 模型才能听懂随便说的话。简单的说法（「紧凑一点」「换封面」「抖音版」「从『…』开始」「突出『…』」）不用模型也能懂。

- **未连接模型** /「还没连上 AI 模型」：什么都没连上。点**连接模型**（Claude Code、Codex、API 密钥或本地模型）。见 [AI 模型](/docs/zh/concepts/ai-providers/)。
- 「模型这次没回应」：连上了，但没有回复。会写明原因：
  - 在时限内没回应，仍然连着：点**重试**（会多等一会儿；成片对话里命令行模型有 180 秒）；
  - 登录过期了：在设置 › AI 里重新登录；
  - 这次没能回答。

如果设置了备用模型，千剪会自动换一个并告诉你（「Claude Code 在 120 秒内没有回应，这次用了 Codex」）。
