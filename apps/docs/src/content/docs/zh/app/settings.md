用 ⌘,（Windows 上是 Ctrl+,）打开设置。顶部的状态行告诉你一切是否就绪；没就绪的话，只说一件要修的事：引擎没在运行、AI 登录过期、缺少下载内容，或某个发布账号退出了登录。

## 通用

- **外观**：语言（应用界面的语言；字幕和发布文案保持每个项目自己的语言）、浅色或深色主题、强调色。
- **新项目**：**自动驾驶**或**先问我**。见 [自动驾驶和先问我](/docs/zh/app/autopilot/)。
- **新项目默认发到**：你的视频默认发哪些平台。首页的平台按钮可以只改这一次请求。
- **从这些文件夹找作品**：全部项目会在这些文件夹里找你的作品，里面来了新录音，首页就会给出建议。
- **整理原始素材**：交付后可选的清理。每个文件都要你确认，而且只会移到废纸篓。
- **我帮别人做视频**：给项目、交付和数据加上客户。
- 版本号和**检查更新**（App Store 版通过 App Store 更新）。可选的使用统计默认关闭，见 [隐私：千剪会发送什么](/docs/zh/concepts/usage-counts/)。

## AI

和你一起规划、剪辑的 AI：你的默认 AI、它是否正常、上次检查是什么时候，以及**换一个 AI…**。某次请求想换，用输入框里的 AI 标签；某个项目想换，在它的页面上切换。

- **登录** Claude Code 或 Codex（浏览器会打开；要求输入代码时粘贴进来）、**测试**、退出登录。
- **模型**：每个服务用的模型，比如 Claude Code 的 Opus 5.5 或 Sonnet 5.5。
- **编程助手**：你自己安装并登录的 Gemini CLI、Cursor CLI、Copilot CLI、OpenCode、Qwen Code、Kimi CLI、CodeBuddy、iFlow 等，标出每个在国内能不能用，并给出其他助手的安装命令。
- **API 密钥**：DeepSeek、通义千问、Kimi、OpenAI、Anthropic 等。保存在系统钥匙串里，千剪只知道有没有设置密钥。通义千问、Kimi、GLM 和豆包的密钥有**接入点**：中国大陆或国际。换了密钥需要重启引擎（页面会提示）。
- **本机模型**：Ollama、LM Studio 或 vLLM，运行起来就能找到。
- **调整顺序**：第一个没回应时下一个用谁。每次切换千剪都会告诉你。
- **高级：不同工作用不同 AI**：规划、挑片段、字幕、发布文案、AI 修改。

详情和排查：[AI 模型](/docs/zh/concepts/ai-providers/)。

## 视频生成

打开「创作」页时才显示。视频服务的密钥（比如可选的 AI 主持人 Hedra）放在这里，存在钥匙串里。付费生成在花钱之前一定会问你。

## 配音

给视频配旁白的免费声音，在 Apple 芯片上离线运行。**中文配音**：Qwen3-TTS（约 3 GB，只需下载一次），五个声音可以试听、选择；还有一个开关，在下载之前先用旧的内置中文声音。**英文配音**：Kokoro（约 330 MB）。见 [配音](/docs/zh/guides/voices/)。

## 水印

在每次导出上加你的账号名、你的标志或生成的标志。见 [水印](/docs/zh/guides/watermark/)。

## 配乐

每条视频的配乐都从这个 CC0 曲库里挑：每首都能试听，可以设为**收藏**或**不再使用**。曲库里没有合适的时用内置配乐；你放在 `~/Music/Reelfold` 里的曲目合适时优先使用。见 [Vlog › 配乐](/docs/zh/guides/vlog/#配乐)。

## 发布账号

千剪发布到哪些账号。你只需登录一次（YouTube：在你自己的浏览器里用 Google 登录），千剪看不到你的密码。账号名和发布时间在「发布 › 账号」里。

- **YouTube**：登录后通过官方 YouTube Data API 发布；还有 **自动发布排好的视频**（默认关闭）。
- **自动发布（官方接口）**：TikTok、X 和 Instagram，暂不支持。
- **视频时长**：按平台设置你自己的最短和最长。

见 [排期和发布](/docs/zh/guides/scheduling-publishing/)。

## 高级

一般用不到。

- **下载内容**：字体、人脸模型、语音识别和免费配音，各自显示**已安装**或**下载**、大小，以及是必需还是可选。下载在后台进行，中断了会续传，用之前会校验。**许可证**列出每个下载内容的许可证。

  | 下载内容 | 大小 | 用途 |
  |---|---|---|
  | 字体和人脸模型 | 约 62 MB | 字幕、封面、人脸跟踪、美颜 |
  | 语音识别（Whisper large-v3-turbo） | 约 1.6 GB | 转写 |
  | 免费配音（Kokoro，Apple 芯片） | 约 330 MB | 没有 OpenAI 密钥时的英文配音。见 [配音](/docs/zh/guides/voices/) |
  | 中文配音（Qwen3-TTS，离线；可选，Apple 芯片） | 约 3 GB | 中文配音。在设置 › 配音里下载 |
  | 配乐曲库（CC0，52 首） | 约 290 MB | 背景音乐。见设置 › 配乐 |
  | 设计封面和幻灯片（可选的浏览器，App Store 版没有） | 约 100 MB | HTML 封面、幻灯片、部分工作流 |

- **引擎**：正在用的视频引擎（应用内置，或你指定的文件夹）、Python、引擎数据文件夹，**重启引擎**。
- **风格默认值**：导入风格文件（字体、品牌色、平台习惯），或恢复千剪默认。
- **首次设置**：重新走一遍 AI、下载内容和平台的设置。
- **帮助与诊断**：**复制诊断报告**（版本、引擎状态和设置；没有密钥、密码或视频）和**打开日志文件夹**。
