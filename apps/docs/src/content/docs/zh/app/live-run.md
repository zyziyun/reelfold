打开一个正在出方案或正在做的项目，它的页面会实时显示进度。你可以盯着看，也可以走开再回来；这里没有必须做的事。

## 顶部

- **一句话**说明它现在在做什么，比如「字幕 — 第 4 条，共 8 条」。
- **进度**百分比和剩余时间，按引擎真实的阶段算（出方案、转写、剪辑、字幕、渲染、质检、文案）。
- 当前模式：[自动驾驶或先问我](/docs/zh/app/autopilot/)，可以在这里切换。

要暂停，就在[项目对话](/docs/zh/app/chat/)里说「暂停」，或者在下面某个部分上点**暂停**。它会停在安全的位置；点**重试**或说「继续」就从那里接着做。

## 做了什么

每一步一条，按顺序，带用时：找到或读了哪些文件、转写了几分钟的语音（或「沿用之前的逐字稿」）、问了哪个 AI、用了多少 token、有几条成片过了这一步，以及它做的每个选择（「AI 决定：…」「按规则决定：…」）。

## 正在做的每一步

做出来的部分一出现就显示在这里：调过色的片段、联系表、母版、封面候选、画好的场景、配音。项目做完后，这一栏叫**是怎么做出来的**。点开一个部分放大看，然后可以：

- **让 AI 改这个**：在对话里针对这个部分发一条消息（「关于『联系表 2』：…」）。
- **暂停**：在安全的位置停下运行。
- **在访达中显示**。

## 实时

**实时**面板是终端样式的真实输出：Claude Code 或 Codex 的输出流（思考、工具调用和回复）和引擎日志，一行一行出来。

- 显示：**全部**、**AI** 或**引擎**。
- **搜索日志**（上一个 / 下一个匹配）、**复制日志**。
- **放到下方**或**放到右侧**，可以调大小，也可以收起。
- 往上翻了？**回到最新**跳回最新一行。

API 密钥、令牌和密码在显示或保存之前就会被去掉。

## 全部看着

**全部看着**（首页「进行中」列表上，或运行页上的「同时看所有进行中的」）把所有正在跑的任务铺在一个屏幕上，每个都有一句话说明、进度和实时日志。「回到页面」返回。
