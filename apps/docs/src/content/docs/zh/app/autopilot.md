千剪有两种工作方式。**自动驾驶**（默认）把你的请求一路做到成片，并记下它做的每个选择。**先问我**会先给你看方案和一条试看，再做剩下的，每个问题都问你。

## 自动驾驶

在首页点「开始做」，请求就变成项目开始跑：

1. AI 出方案：用哪个配方、做几条、发哪些平台。
2. 跑完每一步。平时需要人拍板的地方（删哪些拿不准的口头禅、用哪个开头、哪张封面、什么配乐、竖屏怎么裁、用哪份文案），由 AI 按收件箱里同样的规则来选，并写明理由。
3. 质检通过后，成片自动通过，可以发。

只有真正卡住的事才会进你的收件箱：只有你能给的东西（缺的文件、要你自己写的脚本）、超过花费上限的付费 AI（默认上限是 0）、画面里嘉宾的同意确认，或者某一步停下了。超出上限的花费和同意确认永远不会替你回答。

最多同时跑两个项目，其余的排队（「排队中 · 第 2 个」），重启后位置不变。

## 先问我

选了**先问我**：

- 首页按钮是「让 AI 出方案」。方案写明要做什么、发哪些平台、大概多久、可能花多少钱。用一句话改（「只要 3 条」「不要 9:16」），点「改一下」，再点「开始，先做 1 条试看」。
- 先做一条，风格确认了再做剩下的。
- 每个选择都在收件箱里等你，推荐答案已经准备好。

## 切换

- **新项目**：设置 › 通用 › **新项目**：**自动驾驶**或**先问我**。
- **单个项目**：在它的页面上，标题下面那行写着当前模式，可以直接切换。下一次运行按新的来。

## AI 做的选择

每个项目页面都有 **AI 做的选择**：每个选择一行，写明是谁做的（**AI** 加上服务名，或者没用模型时的**规则**）和理由。比如「剪掉 6 处拿不准的口癖，保留 2 处」「封面：第 3 帧」「配乐：…」「竖屏版本跟随画面主体」「发布文案由 AI 写」。

### 改一个选择

在任意一行点**改**。这个问题会带着所有选项回到你的收件箱；在那里回答后，只重做依赖它的部分（封面、竖屏版本、剪辑），其余都保留。还在跑的项目，等它跑完再改。

## 用 Claude Code 技能或终端

```bash
python -m vstudio.project run --dir <项目> --autopilot      # 不停在试看；选择记录在 project.yaml
python -m vstudio.project run --dir <项目> --ask-first      # 这个项目关掉自动驾驶
python -m vstudio.project decisions --dir <项目> [--history]  # 做了什么选择、谁做的、为什么
python -m vstudio.project reopen --dir <项目> --id cover-pick [--item <成片>]   # 收回一个选择
python -m vstudio.project autopilot --dir <项目> --on|--off [--spend-cap N]
```

`--spend-cap N` 允许自动驾驶批准不超过 N 积分的付费步骤（默认 0：每次花钱都问你）。`--no-judge` 只按规则决定，不调用模型；`--lang en|zh|fr` 设置理由的语言。`reopen` 收回的选择会在下一次运行时等你回答。完整参数见 [命令行参考](/docs/zh/reference/cli/)。
