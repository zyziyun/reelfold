import { Steps, Tabs, TabItem, Aside } from '@astrojs/starlight/components';

这一篇带你把一段口播剪成节奏紧凑、带字幕的竖屏短视频，分别导出小红书和抖音版本，每个平台各配一张封面和一份发布文案。需要你动手的时间大约五分钟，剩下的交给机器。

## 开始之前

- 已经装好千剪（Reelfold）：[Mac 应用](/docs/zh/start/install-mac/) 或 [Claude Code 技能](/docs/zh/start/install-skill/)。
- 准备一段 1 到 3 分钟的口播。竖屏手机录的效果最好；横屏摄像头录像也行，会围绕人脸自动裁成 9:16。
- 可选：口播里容易被识别错的词（产品名、英文术语），在需求里顺带说一下。

## 开始剪

<Tabs syncKey="form">
<TabItem label="在 Mac 应用里">

<Steps>

1. **说需求。** 在首页的输入框里写需求，把视频拖进来：

   > 把这条口播剪一下：去气口、去口头禅和重复，1.1 倍速，加字幕和进度条，不要开头预告。导出小红书和抖音，带封面和发布文案。

   看一眼输入框下面的平台按钮（只对这一次请求生效），然后点「开始做」。

2. **让它跑。** 请求变成项目，全部项目会自动打开它。[实时运行页](/docs/zh/app/live-run/)显示它在做什么、还剩多久，以及陆续做出来的部分。你可以走开，首页的「进行中」会帮你盯着。

3. **口头禅由 AI 判断。** 嗯、呃、结巴这类确定的口头禅一定会删。在[自动驾驶](/docs/zh/app/autopilot/)下，拿不准的那些（「那个」「就是」、说一半重来、重录的句子）也由 AI 判断，并记下删了哪些、留了哪些。剪完后千剪会重新转写一遍，确认没有误删实词。

4. **看看 AI 做的选择。** 项目页面上的 **AI 做的选择** 列出每个选择和理由：去口癖、开头、封面。任何一条都可以点**改**；问题会回到收件箱，只重做依赖它的部分。

5. **打开做好的成片。** 它的状态是**可以发**。点开就能改封面、字幕或版本，也可以跟对话说（「字幕大一点」「封面安静一点」）。见 [修改做好的成片](/docs/zh/app/clip-page/)。

6. **发布。** 每个平台一份成片，各自带封面、标题、正文和标签。**排期发布**把它放进日历；到时间千剪会用内置浏览器打开平台自己的上传页，把视频和文案填好，由你按下发布。

</Steps>

想每一步都自己确认？换成**先问我**（设置 › 通用 › 新项目）。按钮会变成「让 AI 出方案」：你先看方案，做一条试看，拿不准的口头禅在收件箱的「确认去口癖」里由你决定。

</TabItem>
<TabItem label="用 Claude Code 技能">

<Steps>

1. **在视频所在的文件夹里打开 Claude Code**，直接说：

   > 把 talk.mp4 剪一下：去气口、去口头禅和重复，1.1 倍速，加字幕和进度条，不要开头预告。导出小红书和抖音，带封面和发布文案。

   技能会把它交给 [talkinghead 工作流](/docs/zh/reference/workflows/talkinghead/)。Claude 可能会先问你要哪种剪辑风格：记笔记风（稳、干货多）、精剪风（推镜、弹字、节奏快），或者两者混合。

2. **回复去口癖审阅单。** Claude 转写完会给你一张编号的审阅单：先列「待确认」，再列「自动删」、要压短的气口和「保留」的词，每条都带前后文。你回一句就行：

   ```text
   确认 3,5,9 / 保留 7
   ```

   「确认」表示这几条也删；「保留」表示这几条不删（对自动删的条目也有效）。也可以说 `全部确认`，或者用区间，比如 `删 2-4 不删 6`。剪完后会重新转写核对；如果有实词被误删，Claude 会告诉你在哪里，并把那一刀撤回。

3. **看预览。** Claude 先渲染几张预览静帧，再出完整视频。想改就直接说（「字幕大一点」「去掉进度条」）。

4. **封面和文案。** Claude 挑几帧候选做封面，渲染出来给你看；再按各平台的字数限制写好标题、正文和标签。

5. **按平台导出。** 一条干净的母版，按平台各导一份：字幕避开各个 App 的按钮区，响度对齐平台标准。背后用的是 `python -m vstudio.export --platforms xiaohongshu:full,douyin`。

</Steps>

用技能时，发布由你自己来：把成片和写好的文案传到各个平台即可。

</TabItem>
</Tabs>

<Aside type="tip">
所有保留原声的工作流都用同一个去口癖工具，所以上面的回复格式在播客、讲课、vlog 里同样适用。详见 [去口癖与气口](/docs/zh/reference/engine/cleanup/)。
</Aside>

## 最后你会拿到

| 文件 | 说明 |
|---|---|
| 每个平台一条视频 | 9:16，字幕在平台安全区内，响度符合平台标准 |
| 每个平台一张封面 | 按该平台信息流的尺寸 |
| 每个平台一份发布文案 | 标题、正文、标签，按平台字数限制检查过 |

## 剪完还想改

每条成片都能用一句话再改：「开头剪掉两秒」「字幕换成黄色」「再出一个 B站横屏版」。每次修改都可以撤销。见 [成片二次编辑](/docs/zh/concepts/output-edits/)。
