title: 排期和发布
description: 在周历上排好一周的发布，到点收到「该发了」通知，然后发布。YouTube 通过官方 API 发布；其他平台用辅助发布，帮你打开上传页、填好视频和文案，最后由你自己点发布。
---

你会有一张这周的发布日历，每个账号按你定的时间留好发布位；到了每条的时间，你会收到通知。点开它，千剪（Reelfold）打开平台自己的上传页，放好为这个平台导出的视频，填好标题、正文和标签。你检查一遍，做只有你能做的选择，然后自己点发布；页面确认发布成功后，千剪把这条标为已发布。YouTube 不一样：它只通过 YouTube 官方 API 发布，在应用里的发布表单上完成。除非你为 YouTube 打开了**自动发布排好的视频**，否则什么都不会自己发出去。

![发布页的一周看板：按天和平台排好的帖子，哪些已排期、已发布、在等你](../../../../assets/shots/publish-A5-week-board-zh.png)

## 开始之前

- **已经通过、按平台打好包的成片**（见[一个母版发多个平台](/docs/zh/guides/multi-platform/)）。
- **每个平台的发布账号**。一个平台可以有好几个账号。
- Mac 应用。Claude Code 技能能做发布包和排期表，但辅助上传要在应用的内置浏览器里进行，YouTube 也要在应用里登录。

## 账号只登录一次

1. 打开 **设置 › 发布账号**（发布页也能进），逐个添加：平台、名字（比如 `@我的号`）和默认发布时间，比如 `12:00, 19:00`。
2. 点 **登录**，平台自己的登录页会在应用里打开。用平台自己的邮箱、手机号或扫码登录。「使用 Google 继续」「使用 Facebook 继续」「通过 Apple 登录」在应用内置的浏览器里用不了，遇到时千剪会说明。
3. 内置浏览器会在这台 Mac 上为每个账号保留登录状态。应用本身不保存你的密码或 cookie。它通过检查这个账号自己的浏览器会话里是否有平台的登录 cookie（只看名字，从不读取内容）来显示已登录或已退出，所以平台的任何页面都算，包括创作中心首页；在面板里登录后状态会立刻更新。

YouTube 的登录方式不同，见下面的 [YouTube：登录和自己的 Google Cloud 客户端](#youtube-登录)。

只有你在 **设置 › 通用 › 新项目的平台** 里选的平台算你的：它们出现在帖子的 **平台** 里，也只有它们会在设置的状态行里提示「已退出登录，暂时发不了」。其他平台的账号会单独列出，不提醒。

## 排好这一周

**发布** 页是一张周历（也可以切到本月视图）：

- 做好的片子在 **还没排的** 里等着，拖到某一天或某个空位上。
- **AI 帮我排** 会帮你把空位填上。
- 某个账号该发却没排的那天，会显示成断档。
- **确认本周排期** 把排好的帖子标记为就绪。

### 系列

系列让一档固定栏目保持一致：配方、参数、平台、账号，以及更新节奏，比如一周五条。系列里新建的项目会全部继承，日历上也能看出哪个系列落下了。

### 标题

帖子抽屉顶部的标题可以直接改：点一下、输入、按回车（Esc 还原），它对这条的所有平台生效。有标题栏的平台在各自的文案页里还有 **{平台} 标题**，带这个平台的计数：小红书 20（英文和数字按半个字算）、抖音 30、视频号 16、B站 80、YouTube 100。超长只标出，不会截断。**用卡片标题** 去掉这个平台自己的标题。

## 定时发布是怎么工作的

排好的帖子不只是日历上的一格：到了时间，千剪会行动。

1. **到点时**，只要千剪在运行（打开 **设置 › 发布账号 › 登录时打开**，开机后它会待在菜单栏），你会收到通知：「该发了：*标题* → 小红书」。菜单栏图标也会列出该发的帖子。
2. **点开通知**，这条的页面打开，右边是平台上传页，登录的就是这个账号。千剪放好为这个平台导出的视频（小红书用 3:4 或 9:16，YouTube 用 16:9……），填好标题、正文和话题，并框出发布按钮。
3. **你**检查页面，做你的选择（封面、话题、AI 声明、谁可以看），然后点发布。YouTube 的右边不是网页，而是 YouTube 发布表单；在那里点 **发布** 或 **定时发布**。
4. 千剪看着页面：平台确认后（成功页或「发布成功」），这条标为 **已发布**，页面显示链接时一并记下。也可以点 **我已经发了** 手动标记。
5. **如果当时千剪没开**，到点的帖子会排在发布页和首页最上面：「有 2 条该发了」，每条都有 **现在发**。

每条帖子还有 **在浏览器中上传**：平台的上传页在你的默认浏览器里打开（你在那里已经登录）。千剪显示视频文件让你拖进去，标题、说明和标签一样一样复制给你；你在那边点发布，再把帖子链接粘贴回来，标记为已发布。

账号已退出时，填写会停下，请你在页面上登录后 **重新填写**。某个栏位没找到（平台改了页面），步骤列表会标出来；手动补上，并把页面抓取（见下）发给维护的人。

## 现在发一条

1. 在周历上打开一条帖子，选 **打开辅助填写**，或点到点帖子的 **现在发**。平台的上传页会在内置浏览器里打开，登录的就是这个账号。
2. 千剪放好视频文件，在页面允许的地方填好标题、正文和标签。
3. 你检查一遍，做属于你的选择：分区、受众、AI 生成内容声明、Reddit 的版块、Pinterest 的图板。比如 B站的分区和自制 / 转载，永远不会替你预选。
4. 你自己点发布。应用最多把按钮框出来，从不替你点。
5. 页面确认后千剪会自动标为已发；没有确认的话，点 **标记为已发**，贴上帖子链接。

### 平台要求重新登录时

登录会过期。打开的上传页其实是登录页时，自动填写会停在那里，账号显示为已退出。

1. 到 **设置 › 发布账号**，在这个账号上点 **重新登录**。
2. 在内置浏览器里的平台页面登录（密码、扫码，按它的要求来）。
3. 回到那条帖子，再打开一次辅助填写。准备好的内容不会丢。

辅助填写适用于有发布包的项目。某个平台的自动填写还没做好的话，打开它的上传页，用「复制文案」和「显示文件」手动完成。

## 用 Claude Code 技能

Claude 可以把上传之前的事全部做好：

- `python -m vstudio.batch package --batch B --per-day 2 --start 2026-10-10 --times 12:00,19:00` 生成按平台分的文件夹、`schedule.csv` 和确认码。
- 项目日历（`python -m vstudio.project calendar ...`）可以设账号和发布时间，把导出的片子放进下一个空位，并列出断档。
- 不用应用的话，`uploader: manual` 会为每条帖子列出上传页、步骤、`caption.txt`、封面和一份检查清单。

## YouTube 登录

YouTube 只通过 Google 官方 YouTube Data API 发布，从不在内置浏览器里打开。

1. 在 **设置 › 发布账号 › YouTube** 里选 Google 登录方式：**千剪的 Google 应用**（你的版本内置了它时）或 **我自己的 Google Cloud 客户端**。
2. 点 **在浏览器中用 Google 登录**。Google 的登录页在系统浏览器里打开。千剪申请上传视频到你的频道、查看频道名称和播放列表；它不能编辑或删除你的视频。令牌保存在 macOS 钥匙串里。随时可以在那里断开，或在 myaccount.google.com/permissions 撤销。
3. 在 YouTube 帖子上填好表单（标题、说明、标签、类别、公开范围、YouTube 要求回答的观众问题、加工或合成内容的声明、**作为 Shorts 发布**、用封面作缩略图、播放列表），点 **发布**；或者选 **定时**，点 **定时发布**。定时的帖子现在以私享方式上传，到点由 YouTube 自动公开，电脑休眠也没关系。

在 Google 审核通过之前，千剪的 Google 应用会显示「未经验证的应用」页面（点「高级」→「转至 Reelfold」），且最多 100 人可用。**来自未通过 YouTube API 审核的 Google Cloud 项目的上传会保持私享**，需要你在 YouTube Studio 里改为公开。默认配额约每个项目每天 6 条。

使用你自己的 Google Cloud 客户端（一次性设置，约 10 分钟）：

1. 打开 console.cloud.google.com，新建一个项目（名字随意）。
2. 「API 和服务」›「库」：启用 **YouTube Data API v3**。
3. Google Auth Platform（OAuth 同意屏幕）：用户类型选 **外部**，填应用名和你的邮箱。在「受众群体」里把你自己的 Google 账号加为测试用户。
4. 「数据访问」：添加范围 `youtube.upload` 和 `youtube.readonly`（需要播放列表时再加 `youtube`）。
5. 「客户端」›「创建客户端」› 应用类型选 **桌面应用**。复制客户端 ID 和客户端密钥。
6. 粘贴到千剪，然后点 **在浏览器中用 Google 登录**。应用处于「测试」状态时，Google 每 7 天要求重新登录一次；把它发布（自用无需审核）即可保持登录。

Mac App Store 版无法登录 YouTube；每条 YouTube 帖子都可以改用 **在浏览器中上传**。

## 自动发布排好的视频（需你开启）

没有你的点击，什么都不会发出去，除非你打开这个开关。连接 YouTube 之后，**设置 › 发布账号 › YouTube** 里有 **自动发布排好的视频**（默认关闭）。打开后，排好的 YouTube 帖子会提前约一小时以私享上传，并带上 YouTube 自己的发布时间，到点由 YouTube 公开，Mac 睡着也不影响。如果当时千剪没开，晚了 6 小时以内会立即上传；更晚则改为通知你。上传失败最多试 3 次。

| 平台 | 千剪里的官方 API |
|---|---|
| YouTube（含 Shorts） | **可用。** YouTube 只走这条路。 |
| TikTok | 暂不支持。直接发布需要 TikTok 应用审核。在那之前：辅助填写。 |
| X | 暂不支持。发帖需要付费接口套餐。在那之前：辅助填写。 |
| Instagram | 暂不支持。需要关联 Facebook 主页的专业/创作者账号和 Meta 应用审核。在那之前：辅助填写。 |
| 国内平台 | 没有面向个人创作者的公开发布接口。辅助填写。 |

用技能时官方接口默认关闭；即使你开启了，每次上传也都需要你审过的那个发布包的确认码。

## 自动填写漏了栏位：抓取页面

平台会改上传页。每个平台的填写步骤写在一个小的适配文件里；小红书和抖音的适配按栏位的提示文字和标签（「填写标题」「作品简介」「发布」按钮）查找，并有备选，在对照你的真实页面核实之前标为 *未核实*。

1. 在内置浏览器里打开上传页（帖子的页面，或 **设置 › 发布账号** → 该账号的上传页），放入一个视频，让完整表单显示出来。
2. 点浏览器栏里的 **抓取此页**。
3. 千剪把脱敏后的页面结构存到 `~/Library/Application Support/Reelfold/captures/`，并在访达中显示。保留标签、类名、角色、提示文字和短标签；去掉 cookie 和存储（从不读取）、你输入的内容、编辑器内容、图片、链接，以及看起来像名字、账号 ID、手机号或邮箱的内容。
4. 把这个文件发给维护适配的人（或提 issue）。修好的适配放进 `~/Library/Application Support/Reelfold/adapters/`，不用重装应用。

## 值得了解的选项

| 选项 | 作用 |
|---|---|
| 默认发布时间 | 按账号设置，新的日历空位用这些时间。 |
| 登录时打开 | 开机登录后千剪在菜单栏待命，通知准时到。 |
| 自动发布排好的视频 | 只限已连接的 YouTube：排好的 YouTube 帖子自己发出。默认关闭。 |
| 视频时长 | **设置 › 发布账号 › 视频时长**：按平台设置你自己的最短和最长，每次规划都会遵守。 |
| 系列节奏 | 日历期望这个系列每周发几条。 |
| 账号等级 | 有些限制和它有关，比如 X Premium。 |
| AI 标识 | 国内各平台、YouTube、TikTok 和 Meta 都有 AI 生成内容的开关。由你自己勾选，检查清单会提醒你。 |

## 示例指令

- 「这 12 条排到接下来两周：小红书中午、抖音晚上 7 点，各一天一条。」
- 「把『面试技巧』设成一个系列，在我的小红书主号上一周发五条。」
- 「打开明天那条抖音的上传页，帮我填好。」
- 「这周的日历还缺哪几天？」
