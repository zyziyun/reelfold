在**首页**的起步选项里选**录自己**。可以自由讲，也可以先准备提词稿。

## 开录前

1. 选择摄像头和麦克风，检查输入电平。
2. 录软件演示或课程时，从**屏幕**中选择要分享的屏幕或窗口。
3. 调整提词速度和字号。镜像预览和镜像文字是两个独立选项。
4. macOS 询问时允许使用摄像头、麦克风和屏幕录制。拒绝过权限时，到**系统设置 › 隐私与安全性**调整，按系统提示重新打开应用。

## 录一条

点录制按钮或按**空格**开始，**P** 暂停或继续。有提词稿时用 **↑ / ↓** 切换行，**⌘R** 标记重说这一行。停止后保存这一条，并在编辑器中打开。可以保留多条录制，再选要用哪条。

共享窗口关闭或屏幕分享结束时，千剪会暂停整条录制，包括摄像头和麦克风。先保存这一条，再选择新窗口继续录。录制列表会显示**已暂停**或**正在保存**，反映当前状态。

需要换分享的窗口时，先保存当前录制，再开始新的一条。录长课前，先试录一小段，检查画面和声音。

## 编辑和完成

录制在成片编辑器中打开。本地转写后，可以按文字删掉不要的句子、修正字幕，或选中一句**重录**、**在后面加录**。完成前检查衔接和声音。

写清想要的成片，选择平台，再点**完成，做成视频**；也可以直接导出文件。文字稿编辑、补录和外部编辑器导出见[继续编辑成片](/docs/zh/app/clip-page/)。
