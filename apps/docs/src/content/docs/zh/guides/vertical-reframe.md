---
title: 横屏素材的竖屏版本
description: 千剪怎样把横屏素材做成 9:16 和 3:4：跟随主体按镜头裁切、镜头运动平滑，模糊填充保留整幅画面，以及怎样按条切换。
---

横屏素材（航拍、旅行 vlog、录屏）要放进 Shorts、TikTok、Reels、抖音或小红书的竖屏里。千剪有两种做法，每条视频可以单独切换。

## 跟随主体（默认）

每个镜头都围绕画面里重要的东西裁切：人脸、人物、运动的物体和鲜艳的颜色。虚拟镜头很平稳：静止的镜头就不动，有运动就轻轻跟上，转场时缓缓过渡，不会跳。没有模糊背景。

裁不好的镜头会改用整幅画面加模糊背景，比如两个主体离得很远，或者一张没有主体可跟的平坦全景。

## 模糊填充

整幅画面按宽度缩放，下面垫一层它自己的模糊版本。什么都不裁掉。适合大场景、一直写到边上的文字，或者想保留原始构图的时候。

## 切换

- 在成片页面的**竖屏画面**里选**跟随主体**或**模糊填充**。竖屏版本会重新导出；16:9 版本不动。
- 或者跟对话说：「跟随主体」「模糊填充」。
- 自动驾驶时，这个选择会记在 [AI 做的选择](/docs/zh/app/autopilot/#ai-做的选择)里（「竖屏版本跟随画面主体」），可以在那里改。

这个设置出现之前做的项目也能用：千剪会从它的导出文件读出现在是哪种。

## 用 Claude Code 技能或终端

```bash
python -m vstudio.project remake --dir <项目> --item <成片> --do framing=follow
python -m vstudio.project remake --dir <项目> --item <成片> --do framing=blur
```

只重新导出竖屏版本，不跑其他步骤。口播视频有自己的人脸跟踪裁切，见 [口播短视频](/docs/zh/guides/talking-head/)。
