你会得到一条从一堆素材里剪出来的成片 vlog，两种风格任选：**舒缓**（调色、轻微加速、长转场、后配音乐），或**卡点快节奏**（跟着节拍切、变速和慢动作、推镜冲击、弹字、路线地图、音效，你对着镜头说的几句配上字幕，说话时音乐自动压低）。两种都附封面。

![卡点旅行 vlog 竖屏联系表：标题弹出、DAY 日期戳、地点标签、路线地图卡、照片卡片、故障风画面和片尾卡](../../../../assets/shots/fun-vlog.jpg)

## 选一种风格

| | 舒缓 | 卡点快节奏 |
|---|---|---|
| 感觉 | 慢转场、长镜头、环境声，音乐后配 | 跟着节拍切，变速、推镜冲击、弹字、音效 |
| 素材 | 航拍、自然、散步，长而平稳的镜头 | 去了很多地方、有人有吃有动作的旅行，60/120 fps 素材，照片 |
| 声音 | 无声或环境声母版，上面叠音乐 | 音乐主导：背景乐、音效、说话片段（说话时音乐压低） |
| 时长 | 1 到 5 分钟，常见横屏 4K | 20 到 90 秒，竖屏优先，也能出 YouTube |
| 怎么说 | 「安静」「治愈」「电影感」「慢一点」「空镜」 | 「卡点」「快节奏」「有趣」「旅行 vlog」 |

## 开始之前

- **素材**：任意尺寸，横竖都行，SDR 或 iPhone HDR，24 到 120 fps。照片也能用，主要在卡点风格里。
- **音乐**：不用自己准备。用自己的话描述想要的感觉，千剪（Reelfold）会从曲库里挑一首（见[配乐](#配乐)）。卡点风格也可以带一首节拍清楚、你有使用权的曲子。
- **地点和日期**：想要地点标签、DAY 日期戳或地图的话。

如果视频大部分是你在说话，请用[口播短视频](/docs/zh/guides/talking-head/)。vlog 里有几段对着镜头说话没问题。

## 在 Mac 应用里

1. 在首页输入框里描述这条 vlog，把素材拖进来。说清楚舒缓还是卡点、发哪个平台。
2. **方案**里写明风格、平台和标题。
3. **选段与节奏**。千剪为每段素材生成联系表（每 4 秒一格），绝不盲剪。好的片段、顺序、音乐、标题和地图都写进一份剪辑清单。可以让 Agent 先起草，你再调整。
4. **批量**在你的 Mac 上渲染。卡点风格还会生成一份报告：每一刀的卡点检查、转场、叠加元素、音效清单和响度。
5. **选封面**。
6. 审片，发布。

## 用 Claude Code 技能

把素材文件夹交给 Claude，说舒缓还是卡点。技能按 `workflows/vlog` 来做：逐个检查素材，读联系表，写出 `work/edit.json`，然后渲染。卡点风格会先空跑一遍，让你看计划。

```bash
python3 $VSTUDIO/workflows/vlog/scripts/probe.py footage/* --init work/edit.json --style fun \
    --music music/track.mp3 --platform xiaohongshu:full
python3 $VSTUDIO/workflows/vlog/scripts/build_fun.py work/edit.json --dry-run
```

## 配乐

千剪内置一个曲库，共 52 首真实曲目，全部是 CC0 或公有领域（来自 FreePD.com 和 Musopen）：发布的视频里随便用，不用署名。曲库在第一次运行时下载；下载好之前，视频用千剪在你 Mac 上生成的内置配乐。

- **按合适程度挑。** 每条视频的配乐按你描述里的情绪和风格（钢琴、原声、电影感、电子、Lo-fi、纪录片、中国风……）以及剪辑的节奏来挑。卡点短片会选节奏稳定的曲子，曲子的速度决定剪切的密度。
- **不重复。** 一起做的几条视频（一个目标，或一次请求里的几条）在曲库用完之前不会用同一首，最近几条视频用过的曲子也会往后排。
- **设置 › 配乐** 列出整个曲库，每首都能试听，标有 BPM 和授权。可以把一首设为 **收藏**，或设为 **不再使用**。
- **你自己的音乐。** 把你有版权的曲目放进 `~/Music/Reelfold`，合适时会优先使用。CC BY 曲目的署名会写进每个平台的发布文案。

自动驾驶时直接用排第一的那首（这个选择你可以改）；选了 **先问我** 时会给你列表。换掉卡点短片的曲子会重新剪一遍。

## 两种风格各做什么

**舒缓。** HDR 素材先转换，轻度调色，镜头之间统一色彩（每个镜头的白平衡和色调向整片的参考镜头靠拢，切换时颜色不跳），每段单独设速度（空镜比有主体的镜头稍快），晃的地方做防抖，交叉淡化转场，第一帧不黑，结尾淡出。音乐循环铺满、淡入淡出、统一响度；保留环境声时，环境声垫在音乐下面。封面是撕纸剪贴报风格的拼贴。

**卡点快节奏。** 先分析音乐：Beat This!（下载了它的模型之后）找出节拍和小节，剪切就落在上面。开头是全程最精彩几段的快剪 hook，接着标题弹出，然后按顺序放你的镜头，音乐高潮处正好一刀，最后是越来越快的收尾，再接慢速的结尾镜头。在此之上：

- 变速、120 fps 素材的真慢动作、定格成照片卡片；
- 转场：默认是踩在拍子上的硬切，重拍上加推镜冲击。甩镜、闪白、漏光和故障风默认关闭，因为看起来像频闪；想要的话就说（「转场花一点」），也可以只给某一个镜头加；
- 文字：标题弹出、地点标签、DAY 日期戳、时间戳、弹字、路线地图卡、片尾卡，全部在平台安全区内，互不重叠；
- 音效（程序合成，没有版权问题）：甩镜配嗖声，高潮配重击，收尾前的上扬音，照片配快门声；
- 说话片段：保持 1× 原速，去掉卡顿和长停顿，配上字幕，说话时音乐压低。

同时附一版不带音乐的，作为重新配乐用的音轨。

## 值得知道的选项

| 选项 | 风格 | 作用 |
|---|---|---|
| 平台 | 两种 | 决定画布、帧率、安全区、字幕区和响度。默认小红书 9:16。 |
| 调色、亮度 | 两种 | 「太暗」就提亮度，不加暗角。 |
| 统一色彩、胶片风格 | 舒缓 | 统一色彩默认开启。胶片风格（剪辑清单里的 `grade_look`）可选：Cinema neutral、Kodak 2383 soft、Portra warm、Fuji cool、Silver mono 或 Soft bleach，按 35 % 混入。 |
| 转场 | 卡点 | 干净（默认：硬切和推镜冲击）或花哨（甩镜、闪白、漏光、故障风）。 |
| 每段速度 | 舒缓 | 逐段设置；有主体和空镜各有人设默认值。 |
| 节奏 | 卡点 | `fast` 快，或 `relaxed` 放松（长度翻倍）。 |
| 音乐起点、高潮点 | 卡点 | 音乐从哪里开始，大剪切落在哪里。 |
| 地图、标题、片尾卡、弹字 | 卡点 | 每项都可以开关。 |
| 音效 | 卡点 | 默认开启，`sfx: false` 关闭。 |
| 音乐音量、压低幅度 | 卡点 | 背景乐小一点，或说话时压得更低。 |
| 说话去口癖 | 两种 | 卡点默认轻度、只做自动删除；舒缓需要逐段打开。 |

## 示例指令

- 「把这些航拍剪成一条 3 分钟的舒缓 4K vlog，配轻柔的音乐，做个封面。」
- 「东京这趟剪个卡点旅行 vlog 发小红书，用这首歌。加一张城市路线图，每天一个 DAY 戳。」
- 「海边跳起来那段做慢动作，进夜市那里加个甩镜。」
- 「换个配乐：要钢琴的，别那么欢快。」
- 「太快了，放松一点，我说话的时候音乐再小一些。」
