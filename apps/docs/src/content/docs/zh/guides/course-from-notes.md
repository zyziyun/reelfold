---
title: 讲稿做成课程视频
description: 用千剪把讲稿、文档或 Notion 页面做成有配音的课程视频：起草脚本、AI 画的场景、配音、字幕，事后还能重新设计画面或只重画一段。
---

你手里是讲稿，不是素材：一份课程大纲、一篇文档、一个 Notion 页面。千剪按你要的时长把它起草成一集，配上音，把每一段画成图解或动画，加字幕，再按平台分别导出。不需要录像。

## 开始之前

- **你的讲稿**：一个文件（Markdown、纯文本或其他文档）、一个公开的 Notion 页面链接，或导出的 Notion 文件夹。链接会先被读取。
- **一个 AI 模型**，在设置 › AI 里连好。场景由你的 AI 来画（Claude Code、Codex、API 密钥或本地模型）；没有模型就画不出画面。见 [AI 模型](/docs/zh/concepts/ai-providers/)。
- **一个声音**：Apple 芯片上的免费配音、OpenAI 密钥，或你自己的声音。见 [配音](/docs/zh/guides/voices/)。

## 做一集

1. 在首页写需求，加上讲稿：

   > 用这份讲稿做一集 6 分钟的 MCP 课程视频，中文讲解，发 YouTube 和 B站。

   或者

   > 把这个 Notion 页面做成 90 秒的竖屏讲解，发 Shorts 和 TikTok。

2. **开始做。** 讲稿会被完整读一遍，按你要的时长起草成一集：一段一个要点，保留你的例子和比喻，去掉舞台提示。你的讲稿保持原样，不会被直接当成脚本锁定。没有模型时，会按规则起一份简单的草稿，并注明是规则写的。
3. **脚本。** 自动驾驶下直接用草稿；选了**先问我**，就在「脚本定稿」里检查。
4. **配音。** 配音读完后会转写出来和脚本对比，漏了的句子会重读。
5. **画面。** AI 把每一段画成图解或动画，对齐配音的时间点。每一段保留之前都要检查：必须能在视频里播放，不能从网上加载任何东西，要画出来，而不是把句子写在屏幕上。
6. **字幕和导出。** 字幕跟着配音走（中文讲解配中文字幕，英文字幕可选）。每个平台一个版本，带封面和发布文案。

**中文讲解**从头到尾都支持：配音、检查、字幕和时间轴。里面的英文术语会读成英文，见 [配音](/docs/zh/guides/voices/#中文讲解里的英文术语)。

## 重新设计画面

觉得画面太素、或者不合适，可以只重做画面，不动配音：

- 在成片或项目页面点**重新设计画面**，或者
- 跟对话说：「画面太素了」「重新设计画面」「多一点图解」。

AI 会把每一段重新画一遍，再重新渲染、导出。配音和字幕不变。

### 某一段画不出来时

没通过检查的一段，会带着具体问题和修法让 AI 再改一次。还不行，这一段就保留原来的样子（或者先用一张简单的图解），其他段照常重画，页面上会写明：「已重画 13/14 段；第 14 段保留原样」，并提供**重画第 14 段**。

如果整个重画停下了，你的视频不变，仍然是「可以发」。提示会写明是哪一段、为什么，比如「AI 一直想从网上加载数据，视频里做不到」。点**重试**只画还缺的那几段。

## 停下了怎么办

| 提示 | 怎么办 |
|---|---|
| 画面需要 AI 模型来画——Claude Code 没有回应 | 再试一次，或在设置 › AI 里换一个模型。项目在「要你看」里等着，不会渲染出只有文字的视频 |
| 脚本还没分成一幕一幕——里面还是你的讲稿原文 | 点**再试一次**：千剪会根据讲稿起草分幕 |
| 配音几次都漏读了第 N 幕的一句 | 把这句改个说法或拆开。见 [配音](/docs/zh/guides/voices/#配音停下了) |
| 这台电脑上还没有下载免费配音 | **下载免费配音**（约 330 MB），再试一次 |

## 用 Claude Code 技能或终端

配方是 `explainer`（[工作流参考](/docs/zh/reference/workflows/explainer/)）。给做好的成片重做画面：

```bash
python -m vstudio.project remake --dir <项目> --item <成片> --do visuals            # 每一段都重画
python -m vstudio.project remake --dir <项目> --item <成片> --do visuals=missing    # 只画保持原样的那几段
```
